# Code w/ Claude Extended London — Recap interactif

Recap personnel et interactif de la conférence **Code w/ Claude Extended London** (20 mai 2026).

> Compilé par [Robin Detant](mailto:robin.detant@sagora.eu) · [SAGORA](https://sagora.eu)

## Contenu

- TL;DR — 5 cartes pour comprendre la conf en 60 secondes
- Day 1 ↔ Day 2 — comparateur des annonces vs démos
- Les 16 features — matrice filtrable par couche × statut
- Customer case studies — Spotify, Harvey, Lovable, Bun, monday.com, Doctolib, Delivery Hero, Legora
- Founder stage — patterns, judgement calls, Robobun
- Builder stage — Boris Cherny live coding + Thariq Shihipar
- 5 workshops Applied AI — Managed Agents, Memory, Evals, Multi-agent, Live battle
- Thèmes transverses — context window, bottleneck shift, verification, exponential curve
- Glossaire — 16 termes searchables
- Speakers — 13 cartes avec quotes et liens
- Actions à embarquer — Kanban interactif avec persistance localStorage
- Sources — liens catégorisés (officiel, vidéos @claude, customer engineering blogs, recaps)

## Interactions

- `⌘K` / `Ctrl+K` — palette de commandes
- Filtres feature matrix (couche, statut)
- Onglets Day 1 ↔ Day 2
- Workshops en stepper expandable
- Cost calculator Advisor Strategy
- Slider effort level (draggable)
- Harness Planner / Generator / Evaluator interactif
- Glossaire avec filtre fuzzy
- Dark / light theme avec persistance
- Mobile drawer
- Formulaire de contact (mailto)

## Stack

Single-file HTML autonome. Aucune dépendance externe (sauf les iframes YouTube). Toutes les interactions en vanilla JS. Compatible offline une fois chargé.

## Déploiement

Hébergé sur Vercel (voir le badge du repo).
